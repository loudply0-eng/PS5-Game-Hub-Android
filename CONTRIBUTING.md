# Contributing

- Work on a feature branch; do not push directly to `main`.
- Keep changes focused and reviewable.
- Never add game dumps, firmware, console keys, credentials, signing keystores, or private user data.
- Do not add a workflow that runs on every push without maintainer approval.
- Test locally before requesting review and document untested behavior honestly.
- Preserve upstream KytyPS5 Android licensing and notices when integrating its code.
